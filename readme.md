# Gemstone Recommendation App

## Overview

Gemstone Recommendation App is a simple web application that recommends a gemstone based on a user's date of birth. The application determines the user's zodiac sign and displays a suitable gemstone along with its benefits.

---

## Features

* User enters name and date of birth
* Zodiac sign calculation
* Gemstone recommendation
* Benefits display
* Recommendation history
* Local storage support
* Clear history option
* Responsive and clean UI

---

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` using a browser or Live Server.
4. Enter your name and date of birth.
5. Click "Get Recommendation".

---

## Application Flow

1. User enters name and date of birth.
2. Application calculates zodiac sign.
3. A gemstone recommendation is generated.
4. Benefits are displayed.
5. Recommendation is stored in history.

---

## Assumptions

* Zodiac sign is calculated using standard zodiac date ranges.
* Recommendations are predefined and not based on real astrological analysis.
* LocalStorage is used for storing recommendation history.
